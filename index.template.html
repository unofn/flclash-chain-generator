使用指南01 — 04
  1. 下载脚本

    填写至少一个落地节点后生成。

  2. 导入 FlClash

    工具 → 进阶配置 → 脚本 → 添加 → 从文件导入。

  3. 应用到订阅

    在订阅的「扩展 → 脚本」中选择并应用。

  4. 选择链式出口

    在 AI 策略组选落地节点，在「链式入口（机场）」组选第一跳。

使用前了解

需要订阅已有 AI 策略组；覆盖范围由机场规则决定。

默认保留订阅 DNS；TAG DNS 选项开启后会调整 DNS。TUN 和 WebRTC 按客户端设置运行。

已有的客户端选择可能保留，应用后请检查实际出口。

LOCAL SCRIPT

把配置留在本地，
需要时重新生成。

通过命令行读取本地配置与节点凭据，输出到指定目录。适合维护固定节点名称或使用软链接的场景。

>_可重复生成Node.js · 本地文件
01

获取项目

需要已安装 Node.js 18 或更新版本，在终端执行：

TERMINAL
git clone https://github.com/unofn/flclash-chain-generator.git
cd flclash-chain-generator
02

准备本地配置与凭据

将示例配置复制到仓库外，按需修改节点名称、机场设置和凭据路径。

TERMINAL
mkdir -p "$HOME/.chain-studio"
cp local-config.example.json "$HOME/.chain-studio/local-config.json"

示例包含两个节点，分别指向同目录的 exit-a.json 和 exit-b.json。请创建对应凭据文件，或修改配置中的 credentials 路径。每个文件需要以下字段：

凭据格式示例 · 请替换为真实信息
{
  "server": "example.invalid",
  "port": 443,
  "cipher": "2022-blake3-aes-128-gcm",
  "password": "AAAAAAAAAAAAAAAAAAAAAA=="
}

命令行目前支持 SS 2022 的 128 位密钥格式。配置和凭据不要提交到 Git。

03

生成并使用

在项目目录执行，脚本将写入指定输出目录。

TERMINAL
node scripts/generate-local.mjs \
  --config "$HOME/.chain-studio/local-config.json" \
  --output-dir "$HOME/.chain-studio/output" --airport all

输出目录可替换为你的实际目录。再次生成会替换同名文件；如果 FlClash 使用软链接，重新应用订阅后将读取新脚本。

适合哪些情况LOCAL
01
需要重复生成

节点信息更新后，通过本地配置重新生成。

02
维护固定文件路径

输出到指定目录，配合 FlClash 软链接使用。

和网页生成的区别

网页生成需要手动下载导入；命令行可以保留配置中的节点名称并指定输出目录。两者使用不同的节点命名规则。

脚本包含节点密码，请仅在可信的本地环境保存和使用。
